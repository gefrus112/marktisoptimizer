The VPN provider’s .conf file is required. Import is on-device; it is not uploaded.

BEFORE CONNECTING

Know what the profile routes

Your provider’s AllowedIPs and DNS settings decide which traffic uses the tunnel. A full-tunnel route (0.0.0.0/0 or ::/0) may carry all internet traffic and can trigger WireGuard’s Windows firewall/kill-switch behavior. This is not a Roblox-specific latency optimizer and may increase ping.

Administrator approval is required to install, connect, disconnect, or remove the Windows tunnel service. A connected tunnel stays active if Marktis closes and may remain after uninstall. Disconnect and remove it here before uninstalling; successful setup sets it not to auto-start after Windows restarts.

LOCAL PROFILE HANDLING

Provider supplies the service

The app does not provide a VPN server or subscription. It accepts standard WireGuard .conf settings, blocks custom PreUp/PostUp/PreDown/PostDown commands, encrypts the profile with Windows DPAPI in local app data, and does not save a plaintext copy. Never paste private keys into chat.
