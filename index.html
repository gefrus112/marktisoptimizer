The Client

The first thing Roptimer does on launch is detect your Roblox installation. Everything below is Windows-only and works on a local, reversible ClientAppSettings.json.

Windows only · not for Mac

Roblox detection on first run

ImprovesThe biggest FPS levers. Lower texture resolution, cap MSAA samples, disable DPI scaling, simplify the sky and voxel lighting, set an FRM quality level, shorten grass draw distance, or pick a stable renderer. All are local, reversible rendering settings.

Selects the Vulkan renderer where supported as a lower-overhead graphics path.

Prefer OpenGLtrue / false (mutually exclusive)
Selects the OpenGL renderer where supported (legacy GPUs).

            How it works
            
Docs & safety

            
Roptimer is a settings controller, not an injector. It only ever writes a small, reversible ClientAppSettings.json in Roblox's own ClientSettings folders.

          

          local JSON only
        


        

          

            
Three safe steps

            

              
STEP 01
Detect
Install detection scans normal Roblox version folders. A separate Windows-only status check reads only whether RobloxPlayerBeta.exe appears in the process list — no command line, game/server details, or memory.

              
STEP 02
Back up
Existing JSON is copied to a timestamped backup. Unrelated keys are preserved; only allowlisted rendering/geometry keys are merged.

              
STEP 03
Restore
Restore puts managed keys back from the backup. Every write is reversible from within the app or the Boost CLI.

Feature status 38 features

          
An honest catalog of what is implemented safely, what is legacy/limited by Roblox's allowlist, and what is intentionally rejected.

          
Legacy / may be ignored
Unlocking FPS
Writes the legacy FPS flag for older client builds. Current Roblox clients use an allowlist and may silently ignore this flag. Use Roblox Settings > Maximum Framerate for the supported cap up to 240 FPS.
Implemented safely
Texture and cache alterations
Provides texture tiers 0-3 through the allowlisted texture override, plus a conservative cleaner for old Roblox/Roptimer log and temporary files. It does not perform aggressive in-memory cache garbage collection or touch game assets.
Rejected
Disable Roblox telemetry / Crashpad / Backtrace / screenshots
Hidden diagnostic and abuse-reporting flags are not on the local allowlist and are not written. Roptimer sends no analytics of its own, but it does not disable Roblox diagnostics, crash handlers, or background screenshot/reporting systems.
Implemented
Extended graphic tiers
Exposes quality values 0-21 through the allowlisted FRM quality override. Values above 10 use legacy/micro levels and may look different or be ignored as Roblox changes the client.
Implemented
Better FPS / optimization modes
Better FPS, Reduce building lag, Balanced, Maximum performance, Visual quality, and auto-selected mode. All modes write reversible local JSON settings only.
Implemented safely
Reduce building lag
Reduces geometry LOD distance, grass distance, textures, MSAA and motion. It does not remove buildings, change collision, or alter gameplay geometry.
Implemented
Session detection
The V4 Windows client reports whether RobloxPlayerBeta.exe appears in the OS process list using the process image name only; it does not read command-line arguments, game titles, thumbnails, server IDs/addresses, account data, player lists, chat, or memory. The legacy .NET Session page also displays local process paths and window titles.
Implemented
Safe bootstrapper / CLI
RoptimerBoost.exe and Roptimer Boost.command can preview, apply, restore, inspect a session, clean old cache files, print the canonical FastFlag allowlist, launch Roblox through its normal URL scheme, and open the desktop app. Neither injects a DLL.
Rejected
DLL injector / process hooks
No process injection, DLL loading, renderer hooks, memory patching, or executable modification, even when described as optimization only.
Rejected
Fullbright / x-ray / building removal
No exploit-style visuals, world lighting changes, transparent walls, collision edits, or building deletion.
Implemented
C# .NET 8 WPF app
Dependency-free WPF desktop app with a Bubblestrap-inspired settings layout, custom shield icon, blue Lumina theme, and local-settings-only bootstrapper.
Implemented
Settings tab
Interactive website settings builder for optimization mode, FPS target, graphics tier 0-21, texture tier 0-3, cache age, generated Windows/macOS CLI commands, and the embedded FastFlag allowlist docs section.
Implemented
Blue Lumina desktop interface
Blue/purple/cyan desktop app theme inspired by the provided Lumina Hub reference. No green neon status dots.
Implemented
Windows EXE build
GitHub Actions builds Roptimer.exe and RoptimerBoost.exe on windows-latest. RoptimerBoost.exe open launches the desktop app; bootstrap applies safe settings first.
Implemented
macOS companion downloads
Adds an unsigned Python/Tkinter macOS package with .command launchers, a .app terminal launcher, Mac path discovery for /Applications/Roblox.app/Contents/MacOS/ClientSettings, CLI parity, canonical allowlist files, docs, and a macOS build workflow.
Implemented
Lightweight Sirius-style CSS-only website
Rebuilt the portal as a near-black starfield site with a Sirius-like top menu, serif hero, three main tabs, static CSS starfield and gradients, command palette, counters, scroll reveals, Windows/macOS download cards, and FastFlag allowlist docs. No WebGL renderer or Three.js runtime is loaded.
Implemented
CLI and how-it-works docs
Adds a complete CLI reference, performance guide, canonical FastFlag allowlist guide, local JSON/backup explanation, macOS setup guide, GitHub Pages help, downloadable markdown docs, and a docs tab with generated commands.
Implemented safely
Roptimer Script Hub
Original Luau-inspired local UI recipe catalog with code cards, eight screenshots, a Run preview button, and command-palette actions. It is not a Roblox executor and never sends code to a game.
Implemented safely
GUI loading script preview
A local HTML/CSS/JavaScript loading GUI preview with steps, progress bar, and Sirius/Rayfield-like menu styling. No loadstring, game services, remote code, or executor APIs.
Implemented
GitHub Pages Actions deployment
A deploy-pages.yml workflow regenerates screenshots and HTML, validates local links, checks the current Pages build type, and deploys web/ with actions/deploy-pages@v4 when source is GitHub Actions. If source stays legacy, it skips deployment and the committed root index.html fallback serves the site instead of README.md.
Implemented
Root fallback + website validator
build_website.py now generates web/index.html, a root index.html fallback, .nojekyll, 404 pages, site.webmanifest, robots.txt, sitemap.xml, and embeds both the feature catalog and canonical FastFlag allowlist. Its --check mode validates placeholders, local references, JSON, manifest, and allowlist output.
Implemented
Searchable command palette
Ctrl/Cmd+K or / opens a keyboard-navigable palette with 13 actions for tabs, generated CLI commands, downloads, releases, the FastFlag allowlist, safety docs, low-motion focus mode, and the local Script Hub preview. No dynamic code execution.
Implemented
Lightweight CSS starfield and visual effects
Uses a static CSS starfield and gradient backdrop, modest tab/reveal/counter interactions, and an optional low-motion focus mode. No canvas rendering loop, WebGL, GPU bloom, or cursor-follow spotlight.
Implemented
Canonical FastFlag allowlist
Adds fastflags-allowlist.json as the single source of truth for 18 Roblox local ClientAppSettings.json flags in Geometry, Rendering, and User Interface categories. Python and .NET load/validate the same list, the CLI exposes it with --allowlist/allowlist, the website Docs tab renders it, and the WPF app has a dedicated Allowlist page. The legacy FPS flag is explicitly excluded, and telemetry/exploit/anti-cheat flags are rejected.
Rejected
Roblox game script executor / exploit loader
No game script execution, loadstring, executor API, remote script hub, process attachment, or anti-cheat bypass. The Script Hub is strictly a local UI/documentation preview.
Implemented
Rust + Tauri v2 standalone Windows client
Guided x64 NSIS setup wizard for the primary Rust + Tauri Windows client. It uses the built-in WebView2 runtime, has its own Main and grouped Settings UI (Rendering, Geometry, Icons, Allowlist), detects Roblox locally, and manages only allowlisted reversible settings. The Windows app offers System default, Direct3D 11, Vulkan, or OpenGL and the limited local process-name scan.
Implemented safely
Roblox detection on first launch
On first open the Windows client detects whether Roblox is installed by scanning standard version folders and ClientSettings paths (read-only, OS-level). No process attachment, memory reads, or launching Roblox. Results appear on the standalone Main page.
Implemented
Windows-only standalone desktop settings manager
The website has a Client tab; the standalone Rust + Tauri app has a Main page plus grouped Settings sections for Rendering, Geometry, Icons, and Allowlist. The settings manager is Windows-only; the macOS companion is a separate legacy tool.
Implemented
Allowlist features: what each flag improves
The canonical allowlist includes categoryDescriptions and per-flag feature descriptions for all 18 Geometry, Rendering, and User Interface flags. The website and the standalone desktop Allowlist section show searchable flag names and improvement descriptions.
Removed at user request
Three.js / WebGL website scene
Removed from the website to reduce rendering load. The site no longer ships or imports Three.js, a WebGL canvas, or a 3D scene; lightweight CSS gradients and static stars remain.
Implemented safely
Rust safe apply/restore with backups
Rust backend writes only canonical allowlisted ClientAppSettings.json keys, preserves unrelated keys, creates timestamped backups, and can restore managed keys. Legacy FPS flag is not written.
Implemented safely
Allowlisted rendering API preference
The standalone Windows app selects System default, Direct3D 11, Vulkan, or OpenGL using only the mutually exclusive canonical allowlisted switches. Direct3D 12 is not included in the allowlist; unsupported renderer flags are never written.
Implemented safely
Local known-executor process-name check
At startup, every 30 seconds while open, and on request, the Windows app checks exact process image names Xeno.exe, Solara.exe, and JJSploit.exe. Alerts stay in-app; only the image-name field is parsed. Any PID present in tasklist temporary output is ignored and not retained or reported; no paths, command lines, process memory, or network data are collected. This is not antivirus or a complete malware scan. Matches lead to Windows Settings/Windows Security for user review; no process is terminated and no files/software are deleted automatically.
Rejected
Dynamic in-game resolution scaling
Not implemented. The canonical Roblox allowlist has no supported runtime render-scale control. Monitoring game-frame/GPU conditions and changing internal render resolution would cross the app’s no-process-inspection/no-hook boundary. Use Roblox’s official graphics controls instead.
Rejected
Force Roblox onto selected CPU cores
Not implemented. Setting per-process P-core/E-core affinity requires opening and changing the Roblox process, which is outside the local allowlisted-settings boundary. Windows and Roblox retain control of CPU scheduling.
Rejected
ExitLag-style route optimization / jitter mitigation
Not implemented. Route rerouting requires a VPN/relay, driver, or system network-path changes and may send traffic through a third party. Roptimer does not tunnel, intercept, reroute, or optimize Roblox network traffic.
Implemented
Optional Electron Windows desktop client
Adds a separate Electron shell for the standalone desktop UI, alongside the primary Rust + Tauri app. Uses context isolation, sandboxing, no renderer Node integration, a narrow IPC command allowlist, and blocks remote navigation plus HTTP(S)/WebSocket requests. Its local backend preserves the same allowlist-only settings, backups, exact-name process checks, and no-injection/no-memory/no-network boundaries.
Implemented
Guided x64 Windows setup wizards
Configures separate NSIS setup wizards for the Rust + Tauri and Electron apps. Both installers create Start Menu shortcuts and register Windows uninstallers; the Tauri wizard offers a Desktop shortcut option, and the Electron wizard creates a Desktop shortcut. Both can launch the app after setup; no batch launcher is required. The new distribution stops staging the old portable Rust x64 executable.
