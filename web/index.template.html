Marktis Optimizer is a small, lightweight desktop app built with Rust + Tauri. It opens to a dedicated Main page and a grouped Settings area for Rendering, Geometry, Icons, Allowlist, and System. The System tab shows read-only device details and a rough hardware-based preset suggestion; actual game FPS and server ping remain in Roblox Performance Stats (Shift+F5). It checks whether Roblox is installed on first launch and shows only the FastFlags Roblox actually allows, with what each one improves. The Windows desktop app can launch Roblox through the standard roblox:// protocol after a successful settings write. Reversible local settings only: it never patches RobloxPlayerBeta.exe, replaces game audio, reads memory, or injects code.

            How it works
            
Docs & safety

            
Marktis Optimizer is a settings controller, not an injector. It only ever writes a small, reversible ClientAppSettings.json in Roblox's own ClientSettings folders.

          

          local JSON only
        


        

          

            
Three safe steps

            

              
STEP 01
Detect
Install detection scans normal Roblox version folders. A separate Windows-only status check reads only whether RobloxPlayerBeta.exe appears in the process list — no command line, game/server details, or memory.

              
STEP 02
Back up
Existing JSON is copied to a timestamped backup. Unrelated keys are preserved; only allowlisted rendering/geometry keys are merged.

              
STEP 03
Restore
Restore puts managed keys back from the backup. Every write is reversible from within the app or the Boost CLI.
