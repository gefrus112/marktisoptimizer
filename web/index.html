What the desktop app does

Finds any Windows version folder

It scans %LOCALAPPDATA%\Roblox\Versions\version-*, common Program Files installs, the registered client path, optional running processes, and a custom folder. It can also write the persistent shared Roblox ClientSettings profile.

Important 2026 note

The FPS flag is legacy

Roblox’s local FastFlag allowlist currently omits DFIntTaskSchedulerTargetFps. The app can still write it for older builds, but current clients normally ignore it. Use in-experience Settings → Maximum Framerate (up to 240 FPS) for the supported cap.

Rendering options below use flags from Roblox’s published allowlist whenever possible.

Safe Guide

            
Use official Roblox settings first. This companion generates configuration only — it never injects code into Roblox.

          

          

            

              
Recommended workflow

              

                
Generate your profile
Use the Optimizer tab, then copy or download the JSON.

                
Run the Python desktop app on Windows
It finds every installed Roblox version and can write the profile to all of them with backups.

                
Set the supported FPS cap in Roblox
Open the in-experience menu → Settings → Maximum Framerate. Choose up to 240 FPS if available.

                
Restart Roblox
ClientAppSettings.json is read when the client starts, not while a game is already running.

                
Restore if needed
Use the desktop app’s Restore button. It removes only the flags it manages and keeps backups.

              

            

            

              
Manual placement

              
Where the JSON goes

              
%LOCALAPPDATA%\Roblox\Versions\version-*\ClientSettings\ClientAppSettings.json

              
Some client builds also read a persistent shared profile at:

              
%LOCALAPPDATA%\Roblox\ClientSettings\ClientAppSettings.json

              
Roblox updates often create a new version-* folder. The desktop app’s auto-sync handles that; manual users must copy the file again after an update.
