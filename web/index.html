Is this an injector?

No. The app writes a local ClientAppSettings.json file. It does not inject code into Roblox, hook the renderer, or attach to the game process.

Can it remove buildings or add full bright?

No. Those are exploit-style visual changes. The VFX reducer only lowers safe graphics quality settings such as textures, anti-aliasing and grass motion.

Does V2 inject into the client or read my username from Roblox?

No. V2 detects process paths and OS window titles only. The display name is typed by you and stored locally; no Roblox account data, tokens, player lists, chat, or game memory is read.

Will the legacy FPS flag always work?

No. Current Roblox clients may ignore DFIntTaskSchedulerTargetFps because of the local FastFlag allowlist. Use Roblox Settings → Maximum Framerate for the supported FPS cap.

Can I undo the changes?

Yes. The optimizer backs up existing JSON and has a Restore button that removes only the flags it manages.

Does the website connect to my games?

No. This website only offers downloads, features and screenshots. It does not join experiences, read game data, or contact game servers.
